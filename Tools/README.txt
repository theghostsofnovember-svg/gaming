Nawat Kernel 0.2.0 - Unreal Engine 5.7
======================================

محتوى هذه النسخة
----------------
- NawatCore      : حقائق، أحداث، توقف، حفظ
- NawatNarrative : فصول، حوار، تفاعل، استيراد JSON
- NawatAI        : ذكاء العدو، الغطاء، الفرقة والمرافقون
غير مشمول بعد: الواجهة، المشاهد السينمائية، الموسيقى (قيد الكتابة).

المتطلبات
---------
- Windows
- Unreal Engine 5.7 مثبّت من Epic Games Launcher
- Visual Studio 2022 مع حزمة "Game development with C++"

البناء بنقرة واحدة
------------------
1. فك الضغط في مسار قصير، مثل C:\Nawat (المسارات الطويلة تفشل البناء).
2. انقر مرتين على Setup.bat وانتظر عدة دقائق.
3. عند النجاح تظهر [OK] Build succeeded.
   عند الفشل تظهر أسطر الأخطاء، والسجل الكامل في Build\build-log.txt.
   أرسل ذلك الملف لتصحيح الأخطاء.

التثبيت في مشروعك
-----------------
اسحب ملف المشروع (.uproject) وأفلته فوق Setup.bat.
تُنسخ الإضافة إلى Plugins\Nawat داخل مشروعك. افتح المشروع ووافق على إعادة البناء.

إن كان المحرك في مسار غير قياسي
-------------------------------
افتح cmd في هذا المجلد ونفّذ:
    set UE_ROOT=D:\Epic\UE_5.7
    Setup.bat
